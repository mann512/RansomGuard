# RansomGuard

A lightweight, defensive ransomware early-warning agent for MSMEs.

## Problem
CTBF-CS-05 — Ransomware early-warning agent for small businesses.

## Quick start
1. python -m venv .venv
2. .venv\Scripts\activate
3. pip install -r requirements.txt
4. python run.py
5. Open http://127.0.0.1:5000

## Safety
Use benign simulator only on test folders (e.g. C:\demo\business).
NEVER run it on the project folder.
